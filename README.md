# Social Media Platform

This project is a mini social media web application built as part of Task 2.

## Features
- User profiles
- Create posts
- View posts
- Backend API using Express.js

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js

## How to Run
1. Install Node.js
2. Run `npm install`
3. Run `node server.js`
4. Open index.html in browser
